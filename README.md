# Graph Puzzles in Lean

This project formalizes results about snark graphs in Lean.

The proofs include:

- [Proof of Sabidussi's compatibility conjecture with 4 colours](papers/sabidussi/sabidussi_proof.pdf).
- [The cycle double cover theorem for bridgeless graphs](https://github.com/openai/cdc-lean), using OpenAI's Lean formalization.
- [Strong 5-cycle double covers for critical snarks, snarks with colouring defect 3, and permutation snarks](papers/strong-five-cdc/strong_five_cycle_double_covers_baskerville_kp_newpx.pdf).

Interested readers can find details about the formalization and instructions
for checking the proofs in the [formalization guide](GraphPuzzles/README.md).
